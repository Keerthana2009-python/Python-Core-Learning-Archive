# 🎸 Band Name Generator

📌 **Project Overview**
A simple, interactive command-line utility built with Python that generates creative band names by combining the user's hometown city and a pet's name.

🚀 **Features**
* **Interactive Prompts:** Captures real-time user text inputs via the terminal console.
* **String Concatenation:** Dynamically links separate text variables into a single formatted string output.

🛠 **Technologies Used**
* Python 3

▶️ **Running the Project**

### Execution
Run the script file via your terminal window:
```bash
python main.py
```

📸 **Example Output Execution**
```bash
Welcome to the Band Name Generator.
Which city did you grow up in?
Bristol
What is the name of a pet?
Rex
Your band name could be Bristol Rex
```

📚 **Concepts Practiced**
* Standard Console Output (`print()`)
* User Input Capture (`input()`)
* String Concatenation and Variable Assignment
